Javaについての説明です。

Javaは世界中で利用されているプログラミング言語です。 業務システム、Webアプリ、Androidアプリ開発など幅広い分野で使用されています。 「一度書けばどこでも動く」という特徴を持ち、初心者学習にもよく利用されます。

型について

int型

整数を扱うための型です。 -2147483648 ～ 2147483647 までの数値を扱えます。 年齢や個数など、小数点を含まない数字を扱う際に使用します。

double型

小数点を含む数値を扱う型です。 身長、体重、平均点などの計算で使用されます。

char型

1文字だけを扱う型です。 文字はシングルクォーテーションで囲みます。 例：'A' 、'あ'

boolean型

true または false の2つの値だけを扱う型です。 条件判定などで利用されます。

String型

文字列を扱う型です。 複数の文字を保存でき、「" "」ダブルクォーテーションで囲みます。 例："Hello"

if文について

if文は条件によって処理を分岐させるために使用します。 「もし○○ならこの処理をする」という意味を持ちます。

elseについて

elseは「それ以外の場合」の処理を実行します。 ifの条件に当てはまらなかった場合に利用されます。

else ifについて

複数の条件を判定したい場合に使用します。 条件を順番に確認し、当てはまった処理を実行します。

繰り返し処理について

for文

決まった回数だけ処理を繰り返したい場合に使用します。

while文

条件がtrueの間、処理を繰り返します。

クラスについて

クラスは設計図のようなものです。 変数やメソッドをまとめて管理できます。 Javaはクラスを中心にプログラムを作成します。

メソッドについて

メソッドは処理をまとめた機能です。 同じ処理を何度も再利用できるようになります。

アクセス修飾子について

public

どこからでもアクセス可能な修飾子です。 他のクラスからも利用できます。

private

同じクラス内でのみ利用可能な修飾子です。 データを安全に管理するためによく使われます。

protected

同じパッケージ、または継承したクラスから利用できます。

staticについて

オブジェクトを作成しなくても使用できる機能です。 共通機能などによく利用されます。

コンストラクタについて

オブジェクト生成時に自動で呼び出される特別なメソッドです。 初期値を設定する際によく使用されます。

packageについて

クラスを整理するための機能です。 関連するクラスをグループ分けできます。

配列について

複数の値をまとめて管理するための機能です。 同じ型のデータを複数保存できます。

ArrayListについて

要素数を自由に増減できる便利なコレクションです。 配列より柔軟にデータ管理できます。

例外処理について

try

エラーが発生する可能性のある処理を記述します。

catch

エラー発生時の処理を記述します。

finally

エラーの有無に関係なく最後に実行される処理です。

sqlについての説明です。(Oracle)

SQLはデータベースを操作するための言語です。 主にデータの検索、追加、更新、削除などを行う際に使用されます。 学習ではOracle Databaseを利用し、基本的なSQL文やデータベース操作について学んだ。

SELECT文について

SELECT文はデータベースからデータを取得する際に使用します。 必要な列や条件を指定してデータ検索を行えます。

INSERT文について

INSERT文はテーブルに新しいデータを追加する際に使用します。

UPDATE文について

UPDATE文は既存データの内容を変更する際に使用します。 WHERE句を利用することで特定データのみ更新できます。

DELETE文について

DELETE文はテーブル内のデータを削除する際に使用します。 WHERE句を指定しない場合、すべてのデータが削除されます。

WHERE句について

WHERE句は条件を指定してデータを検索するために使用します。 特定の条件に一致したデータのみ取得できます。

ORDER BYについて

ORDER BYはデータを昇順や降順に並び替える際に使用します。 ASCは昇順、DESCは降順を表します。

GROUP BYについて

GROUP BYは同じ値ごとにデータをグループ化する際に使用します。 集計関数と組み合わせて利用されることが多いです。

集計関数について

COUNT

データ件数を取得する関数です。

SUM

数値データの合計を求める関数です。

AVG

平均値を求める関数です。

MAX

最大値を取得する関数です。

MIN

最小値を取得する関数です。

JOINについて

JOINは複数のテーブルを結合してデータを取得するために使用します。 関連するデータをまとめて表示できます。

INNER JOIN

両方のテーブルに一致するデータのみ取得します。

LEFT JOIN

左側テーブルのデータをすべて取得し、一致する右側データを結合します。

CREATE TABLEについて

新しいテーブルを作成する際に使用します。 列名やデータ型、制約などを設定できます。

ALTER TABLEについて

既存テーブルの構造を変更する際に使用します。 列追加、列削除、データ型変更などが行えます。

DROP TABLEについて

テーブル自体を削除する際に使用します。 データもすべて削除されます。

PRIMARY KEYについて

テーブル内でデータを一意に識別するためのキーです。 重複やNULLを許可しません。

FOREIGN KEYについて

他テーブルとの関連付けを行うためのキーです。 テーブル間の整合性を維持できます。

NOT NULL制約について

NULL値を禁止する制約です。 必須入力項目などに使用されます。

UNIQUE制約について

重複データを禁止する制約です。 同じ値を複数登録できなくなります。

トランザクションについて

データベース処理をひとまとまりとして管理する仕組みです。 途中で問題が発生した場合、処理を元に戻せます。

COMMITについて

現在のトランザクション内容を確定する命令です。 COMMIT後は変更内容が保存されます。

ROLLBACKについて

トランザクション開始前の状態に戻す命令です。 誤った更新を取り消す際に利用します。

SAVEPOINTについて

トランザクション途中の保存地点を作成する機能です。 指定地点まで処理を戻せます。

htmlについての説明です。

HTMLはWebページを作成するためのマークアップ言語です。 文章、画像、リンク、表などを配置し、Webページの構造を作成できます。 タグを使用して要素を囲みながら記述します。

HTMLタグについて

HTMLではタグを使用して要素を定義します。 開始タグと終了タグで囲むことで内容を表示できます。

見出しタグについて

h1 ～ h6

見出しを表すタグです。 h1が最も大きく重要な見出しで、数字が大きくなるほど小さい見出しになります。

段落タグについて

pタグ

文章の段落を作成する際に使用します。

改行タグについて

brタグ

文章を改行する際に使用します。 終了タグは不要です。

リンクについて

aタグ

別ページへ移動するリンクを作成する際に使用します。 href属性にURLを指定します。

画像表示について

imgタグ

画像を表示する際に使用します。 src属性に画像パスを指定します。

リストについて

ulタグ

順番のないリストを作成する際に使用します。

olタグ

順番付きリストを作成する際に使用します。

liタグ

リストの項目を表します。

表について

tableタグ

表を作成する際に使用します。

trタグ

表の行を作成します。

thタグ

表の見出しセルを作成します。

tdタグ

表のデータセルを作成します。

フォームについて

formタグ

入力フォームを作成する際に使用します。

inputタグ

文字入力欄やボタンなどを作成できます。 type属性によって機能が変化します。

textareaタグ

複数行の文章入力欄を作成できます。

selectタグ

選択式の入力項目を作成できます。

属性について

タグに追加情報を与えるものです。 id、class、src、hrefなどがあります。

id属性について

ページ内で一意の名前を付ける際に使用します。 CSSやJavaScriptで特定要素を指定できます。

class属性について

複数要素に同じ名前を付ける際に使用します。 同じデザインをまとめて適用できます。

divタグについて

要素をグループ化するためのタグです。 レイアウト作成でよく利用されます。

コメントについて

HTML内にメモを残す機能です。 ブラウザには表示されません。

セマンティックタグについて

headerタグ

ページやセクションのヘッダー部分を表します。

mainタグ

ページの主要内容を表します。
